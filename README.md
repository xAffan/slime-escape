# 🟢 Slime Escape: Multiplayer

**Slime Escape: Multiplayer** is an exciting indie platformer built with the [Godot Engine](https://godotengine.org/)!  
Race head-to-head with a friend in this two-player showdown where the fastest slime wins. Dodge obstacles, outmaneuver hazards, and sprint your way to victory across **10 challenging levels**.

## 🕹️ Overview

In **Slime Escape: Multiplayer**, two players compete in a high-speed race through perilous levels.  
Each player must navigate tricky terrain and avoid enemies to be the first to cross the finish line.  
Will your slime prove to be the fastest?

---

## ✨ Features

- **10 Unique Levels** – Experience diverse challenges and obstacles in every level.
- **Competitive Multiplayer** – Two players race simultaneously; whoever finishes first wins!
- **Distinct Controls:**  
  - **Player 1:** Uses the control keys (arrow keys)  
  - **Player 2:** Uses WASD for movement and jumping
- **Challenging Obstacles & Enemies** – Strategically dodge hazards and outmaneuver your opponent.
- **Built with Godot** – Enjoy a smooth, engaging experience powered by the open-source Godot Engine.

## 📥 Installation

### 🔧 Running the Game Locally

1. **Download the Project Files:**  
   Obtain the project files from your preferred source.
2. **Install Godot Engine:**  
   Download and install [Godot Engine](https://godotengine.org/download) (ensure compatibility with the project version).
3. **Open the Project:**  
   Launch Godot, click **"Import"**, and select the `project.godot` file in the project folder.
4. **Run the Game:**  
   Click the **"Play"** button within Godot to start the race!

### 🖥️ Download Prebuilt Versions

- **Windows** – Download the Windows build.
- **Linux** – Download the Linux build.  
*Note: There is no prebuilt version for macOS.*

## 🎮 How to Play

- **Objective:** Race against your opponent to be the first slime to cross the finish line.
- **Controls:**  
  - **Player 1:** Use the arrow keys (control keys) for movement and jumping.  
  - **Player 2:** Use `W` (up/jump), `A` (left), `S` (down), and `D` (right) for movement and jumping.

🔹 **Tip:** Timing and precision are key—study the level layouts and plan your moves to outpace your opponent!
