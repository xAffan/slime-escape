# 🟢 Slime Escape

**Slime Escape** is an indie, singleplayer platformer built with the [Godot Engine](https://godotengine.org/).  
Guide your adorable slime through **10 uniquely challenging levels**, dodging enemies and obstacles to reach the exit!

## 🕹️ Overview

In **Slime Escape**, you take control of a bouncy, squishy slime on a quest to escape a dangerous world.  
Each level is designed to test your reflexes and platforming skills, with tricky enemy patterns and deadly hazards.  
Will you be able to guide the slime to safety?  

---

## ✨ Features

✔ **10 Unique Levels** – Each with its own set of challenges and obstacles.  
✔ **Adorable Protagonist** – A cute slime with smooth animations and physics.  
✔ **Challenging Enemies** – Learn their patterns to avoid getting caught.  
✔ **Simple & Intuitive Controls** – Easy to pick up but tricky to master!  
✔ **Built with Godot** – Powered by the open-source Godot Engine for a seamless experience.

## 📥 Installation

### 🔧 Running the Game Locally

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/yourusername/slime-escape.git
   cd slime-escape
   ```
2. **Install Godot Engine:**  
Download and install [Godot Engine](https://godotengine.org/download) (compatible with version 3.x or 4.x, depending on the project settings).  
3. **Open the Project:**  
- Launch Godot  
- Click **"Import"**  
- Select the `project.godot` file in the project folder  
4. **Run the Game:**  
Click the **"Play"** button inside Godot to start the adventure!  

### 🖥️ Download Prebuilt Versions

For a hassle-free experience, grab the latest **Windows, Linux, or macOS** build from the [Releases](#) page.

## 🎮 How to Play

- **Objective:** Get the slime to the goal while avoiding all enemies.  
- **Controls:**  
- **Move Left/Right:** `Arrow Keys`
- **Jump:** `Space Bar`  

🔹 **Pro Tip:** Watch enemy movement patterns before making a move—patience is key!
